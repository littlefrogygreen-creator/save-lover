# Original material sounds

These six mono PCM WAVs are original synthesized Foley sketches created by assets/build-foley.cjs. They are not location recordings or third-party samples. Cup uses decaying ceramic resonances; pour mixes filtered noise and droplets; touch and pad use shaped fabric/paper noise; fall combines a low impact and a later ceramic rattle; press is a restrained tactile thud.

Playback is decoded once and shared. If loading or decoding fails, the original procedural sound provides a fallback. Sound mute stops active sample voices as well as muting the procedural bus. On-site speaker loudness must be checked with the actual hardware.
