# Grandma artwork

Generated with the built-in imagegen tool. The scene layers and positions are defined in index.html.

- grandma-seated.png: right-hand seated character, facing left.
- grandma-happy.png: happy dialogue portrait.
- grandma-worried.png: uncomfortable dialogue portrait.
- tea-room.png: round table with long white cloth, menu, dim sum and tea set; empty chairs stay visible during collapse.
- grandma-seated-v2.png: current seated character without a baked-in chair.
- grandma-lying.png: current transparent collapse sprite.

The original concept boards live in output/art-directions. Layer extraction prompts are saved in round-table-prompts.txt.

The refined theatre uses tea-room-clean.png (no baked-in tea props), grandma-unwell.png and grandma-falling-v2.png. Generation prompts are in theatre-prompts.txt. The corrected falling face uses closed eyes and a small open mouth rather than a smile. All new raster art was generated with built-in imagegen.

Portraits are shown only for grandma dialogue. Chest discomfort lines select the worried expression; other lines select happy. Reset and other speakers do not display a permanent character strip.
